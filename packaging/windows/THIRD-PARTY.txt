Third-party software in this folder

AudioCrate itself is GPL-2.0-or-later (AudioCrate-GPL-2.0.txt). This file lists what else is in the folder, under which
licence, and where the source is. The licence texts are in this LICENSES folder unless a line says otherwise.


Libraries for the chiptune formats and the visualizer (libs folder)

  libgme.dll                  Game_Music_Emu 0.6.5, LGPL-2.1-or-later. Source: https://github.com/libgme/game-music-emu
                              Text: libs\LICENSES\libgme-LGPL-2.1.txt
  libfurnace_wrap.dll         AudioCrate's wrapper (_furnace_wrapper_src in the source zip) around the Furnace engine, tag dev250
                              (commit 158e41f), GPL-2.0-or-later, built with the patches in source\winlibs-patches.
                              Furnace's extern folder has code under other licences, all in libs\LICENSES\furnace-extern.
                              Source: https://github.com/tildearrow/furnace
  libsid_wrap.dll             AudioCrate's wrapper (_sid_wrapper_src in the source zip) with libsidplayfp 3.1.1 and libresidfp 1.2.2,
                              GPL-2.0-or-later. Source: https://github.com/libsidplayfp
  projectM-4.dll, projectM-4-playlist.dll
                              libprojectM 4.1.6 (the Milkdrop visualizer), LGPL-2.1, with GLEW 2.3.1, built with the
                              patches in source\winlibs-patches. Source: https://github.com/projectM-visualizer/projectm
                              Texts: libs\LICENSES\projectM-* and glew-LICENSE.txt

  These are built without changes other than the patches listed above, for 64 bit Windows, and import system DLLs only.
  The LGPL libraries are separate DLLs, so they can be replaced by other builds of the same version.

Source code

The source of AudioCrate (the Python files, the two wrapper programs and the files that build this release) is in the
source folder of this release, in AudioCrate-source.zip, next to the patches that were applied to Furnace, the SID wrapper,
projectM and openmpt123 for Windows (winlibs-patches). The sources of the other GPL and LGPL parts are at the addresses
above, at the versions named. Anyone who got this folder from the AudioCrate project can ask the project for a copy of the
source of any part of it that is not already at one of those addresses.
